# SprintFlow UI Plan

## Public Pages

- Login
- Register

## Protected Pages

- Dashboard
- Projects
- Project Details
- Create Project
- Edit Project
- Create Issue
- Issue Details
- Edit Issue
- Profile

## Main Layout

After login, the application will use:

- Top navigation bar
- Left sidebar
- Main content area

Sidebar links:

- Dashboard
- Projects
- Profile
- Logout

## Dashboard

The dashboard will show:

- Total projects
- Open issues
- Completed issues
- Critical issues
- Recent projects
- Recent activity
- Project progress

## Project Details

Each project page will show:

- Project name
- Description
- Progress
- Create Issue button
- List of project issues

Each issue will show:

- Title
- Type
- Priority
- Status
- Due date
